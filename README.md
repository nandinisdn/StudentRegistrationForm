# Student Registration Form

A simple and user-friendly multi-step Student Registration Form built using **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

[View Student Registration Form](https://student-registration-form-cyan.vercel.app/)

## 📌 About the Project

This project allows students to complete their registration through multiple steps. It collects personal information, educational details, and residential address, and displays all entered information on a confirmation page before final submission.

## ✨ Features

- User registration with email and password.
- Password visibility toggle.
- Real-time password validation.
- Personal details collection.
- Education details collection.
- Address details collection.
- Form validation.
- Data storage using Local Storage.
- Confirmation page to review entered details.
- Registration success popup.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/nandinisdn/StudentRegistrationForm.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.

4. Complete the registration form and review your details.
